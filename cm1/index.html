Comprendre les sources et les limites du CM1

Base nationale IRVE statique consolidée par le Point d’Accès National transport.data.gouv.fr ; déclarations des aménageurs et opérateurs, actualisation nocturne. Snapshot téléchargé le 22 octobre 2026. Les dates de mise à jour des points peuvent être plus anciennes. Base officielle en transition et en version bêta : couverture inégale, notamment outre-mer.

Une ligne source représente un point de recharge. Les stations sont regroupées par identifiant de station. Les maxima de puissance correspondent au point le plus puissant renseigné, pas à une puissance garantie pour chaque véhicule. Un filtre de puissance ou d’accès sélectionne des stations : le compteur de points inclut ensuite tous les points de ces stations.

Les codes commune absents restent « non renseignés » ; aucun code postal n’est utilisé à leur place. Les points sans coordonnées valides restent dans les fichiers téléchargeables et les compteurs. Une absence de point sur la carte ne démontre pas l’absence d’équipement sur le terrain. Les coordonnées peuvent être approximatives ou incohérentes ; aucun géocodage n’est inventé.

Le CM1 établit l’offre observée. Il ne démontre pas un besoin d’installation, une rentabilité ou une saturation. Le parc automobile, la recharge privée, les flux de passage et les coûts seront à examiner ensuite, après validation du marché par l’enseignant.
